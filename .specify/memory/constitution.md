# 需求实施原则

版本：0.2.0；生效：2026-11-10；状态：试运行。

团队流程、确认节点、模型选择、重试阈值和恢复规则以 [AGENTS.md](../../AGENTS.md) 为唯一维护位置，本文件只声明原生 Spec Kit 的治理原则：

1. 当前需求和用户决定可追溯；产品/验收有疑问先澄清，不以猜测开工。
2. 原生 spec/plan/tasks 管需求，目标仓库自己的规则管代码；只改批准范围。
3. 完成以当前代码的真实测试、必要独立检查和整体验证为依据，上线另记。
4. 模型从执行时目录选择；中断读取文件现场、核对旧执行者，再接续；未知不是通过。
5. 本地文件和按需工具足够，原生能力优先，不维护重复任务/日志/知识系统。
